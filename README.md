# FIAE AP2 Lernstudio (Codex-Upgrade 3.0)

موقع دراسة وتدريب محلي شامل للأقسام الكتابية الثلاثة في **AP2** لتخصص **Fachinformatiker/in Anwendungsentwicklung (FIAE)**، يعمل بالكامل بدون إنترنت أو خادم.

## التشغيل

1. إن حمّلت الأرشيف `AP2-FIAE-Lernstudio.zip`، فك ضغطه بالكامل أولًا.
2. افتح `index.html` بالنقر المزدوج في Chrome أو Edge أو Firefox.
3. احتفظ بملفات CSS وJavaScript في المجلد نفسه. لا يحتاج المشروع إلى تثبيت مكتبات أو تشغيل خادم.

## ما الجديد في تحديث القياس والتدريب (Codex-Optimierungen)؟

1. **9 نماذج محاكاة امتحانية كاملة تحت الوقت (`#simulator`):**
   - **3 نماذج لكل قسم كتابي:**
     - **النموذج A (Diagnose):** تشخيص المستوى وبناء الحلول من الصفر.
     - **النموذج B (Nach der Wiederholung):** تتبّع الكود (Code-Tracing)، اكتشاف الأخطاء المنطقية وتصحيحها (Bugfixing & Refactoring).
     - **النموذج C (Vor der Prüfung):** محاكاة ما قبل الامتحان ودمج موضوعات الكتالوج المحدّث.
   - في **WiSo** تتنوع الأسئلة بين **الاختيار المتعدد (MC)**، **الترتيب الزمني (Reihenfolge)**، **المطابقة (Zuordnung)**، **صناديق الحساب (Rechenkästchen)**، و**قراءة الجداول (Tabellenauswertung)**.
2. **خريطة تغطية الكتالوج التفاعلية (`#katalog`):**
   - مبنية وفق **AkA-Prüfungskatalog (الطبعة الثانية السارية منذ صيف 2025)**.
   - تربط كل بند بالدرس والتمرين ونموذج المحاكاة والامتحانات السابقة، وتميّز بصرياً بين:
     - `Prüfungsniveau` (**عليه تدريب بمستوى الامتحان**)
     - `Geübt` (**عليه تدريب**)
     - `Erklärt` (**مشروح فقط**)
3. **قائمة المراجعة الشخصية وتشخيص سبب خسارة النقاط (`#review`):**
   - بجانب التقييم والنقاط، يمكنك تسجيل **سبب خسارة النقاط**:
     - `📖 فهم المطلوب / Operator`
     - `⚙️ خطأ في المنطق أو الحساب`
     - `⚠️ نسيان حالة حدّية (Edge Case)`
     - `⏱️ ضيق الوقت`
   - يجدول النظام مراجعة متباعدة (**Wiedervorlage-Datum**) ويربط الخطأ بالدرس وتمرين مشابه (**Zwillingsaufgabe**).
4. **تقوية تصحيح الإجابات الحرة (`Pseudocode`, `SQL`, `UML`, الحسابات):**
   - **سلم نقاط جزئية تفاعلي (Teilpunkte-Checkliste):** يبيّن أي خطوة تستحق النقاط.
   - **حلول بديلة مقبولة (Alternative Lösungswege):** يعرض أكثر من طريقة صحيحة يقبلها مصححو IHK.
   - **اختبار الحالات الحدية على بيانات فعلية (Randfall-Test):** مثل اختبار عميل بلا طلبات في `LEFT JOIN` (الشرط في `ON` مقابل `WHERE`) أو خطأ المجموعة الأخيرة في `Gruppenwechsel`.
5. **فهرس الامتحانات السابقة والتوقعات القابل للتصفية (`#pruefungsindex`):**
   - تصفية حسب الدورة (`Winter 2021/22` حتى `Winter 2025/26`) والقسم والموضوع.
   - يفصل بصرياً بين **الإحالات الامتحانية الموثقة (`📌 Belegte Altprüfungs-Referenz`)** وبين **التوقعات (`🔮 أتوقع ورود هذه المعلومة` مع سبب الترجيح)**، ويعرضها أيضاً داخل كل درس مرتبط بها.
6. **إبراز الكلمات المفتاحية بخط غامق (`<b>...</b>`) في جميع الشروح:**
   - تم تمييز جميع المصطلحات والكلمات المفتاحية والأرقام القانونية بخط غامق واضح في الشرح الألماني والعربي وفي حلول جميع التمارين.

## هيكل الملفات

- `index.html`: الصفحة الأساسية وهيكل التنقل.
- `style.css`: التصميم المتجاوب، إبراز الخط الغامق، أزرار المحاكاة، وبطاقات الإحالات والتوقعات.
- `app.js`: محرك العرض، مؤقت المحاكاة، تصحيح النقاط الجزئية، تشخيص الأخطاء، والفلاتر التفاعلية.
- `content.js`, `content-it.js`, `content-wiso.js`: المحتوى الأساسي للدروس.
- `content-depth-core.js`, `content-depth-data.js`, `content-depth-systems.js`, `content-depth-wiso.js`: الشروح الموسّعة والأمثلة التطبيقية.
- `content-exam-algorithmen-sql.js`, `content-exam-planung-uml-qualitaet.js`, `content-exam-wiso-komplett.js`: وحدات التدريب الامتحاني المكثف.
- `content-simulations.js`: النماذج التسعة الكاملة للمحاكاة الامتحانية (`t1-a/b/c`, `t2-a/b/c`, `wiso-a/b/c`).
- `content-katalog-index.js`: خريطة تغطية الكتالوج (`katalogMatrix`)، فهرس الامتحانات والتوقعات (`examIndex`)، وسلالم النقاط الجزئية والحالات الحدية (`exerciseMeta`).
